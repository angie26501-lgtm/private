# 保戶版報告書｜集中上架資料庫

財顧芸 陳芸琪 的保戶版報告書網路版，依客戶代號分子目錄。

⚠️ 本資料庫為 **Public**（免費帳號的 GitHub Pages 需要公開）。任何人都能瀏覽檔案列表與原始碼，所以只放「已加密」的客戶版。

## 目錄結構

```
private/
├── robots.txt            ← 全站禁止搜尋引擎收錄（不要刪）
├── README.md
├── _template/            ← 報告書範本（全虛構「小安」，技能自動取用）
│   └── v4.12/
├── tools/check.py        ← 上傳前檢查
└── {代號}/               ← 每位客戶一個子目錄，只用英文代號
    ├── index.html        ← 網路版總目錄（傳給客戶的入口）
    ├── {代號}-review.html  ← 客戶版報告書（內容需加密）
    └── {代號}-plans.html   ← 方案第二頁（通用內容，不含客戶資料）
```

客戶網址：`https://angie26501-lgtm.github.io/private/{代號}/`

## 三條固定規則

1. **子目錄只用英文代號**，不用本名或拼音全名。
2. **只上傳客戶版**：內部核對版、本機版總目錄（有通行碼）、PDF、保價表原圖、build.py 一律不上傳。刪掉的檔案在歷史紀錄裡還查得到，所以上傳前先檢查。
3. **報告書內容必須加密**（AES-GCM，通行碼解密）。只有 SHA-256 通行碼頁、內容是明文的檔案不可上傳。

## 上傳前檢查

```bash
python3 tools/check.py          # 檢查全部客戶子目錄
python3 tools/check.py jane     # 只檢查一位
```

出現 ❌ 就先不要上傳。

## 客戶要求刪除資料時

刪除子目錄後，還要清除 git 歷史紀錄，才算真正刪除；請找 Claude 協助處理。
